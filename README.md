# Second Brain — 나처럼 판단하는 AI 만들기

내가 LLM과 신중하게 나눈 대화에는 나의 선택, 거절, 수정 요청이 그대로 남아 있습니다.
**Second Brain**은 그 흔적에서 판단 기준을 증류해, 새 작업에서 "일반적으로 좋은 답"이 아니라
**"나라면 선택할 답"**을 만들어주는 개인화 볼트 시스템입니다. Claude Code와 Codex에서 모두 작동합니다.

## 구조 — 4층 볼트

| 층 | 역할 | 접근 |
|---|---|---|
| `0_원본/` | 내가 던져 넣는 raw 데이터 (대화 내보내기, 이력서, 산출물 — 이름 자유) | 평소엔 안 읽음 |
| `1_두뇌/` | 증류된 판단 규칙 + 팩트카드 (원문 인용·출처 링크 동봉) | 작업의 판단 기준 |
| 지휘자 | `AGENTS.md`(본문) + `CLAUDE.md`(한 줄 임포트) — 요청마다 필요한 모듈만 로드 | 항상 |
| `3_형식/` | hwp/hwpx·xls/xlsx 산출 워크플로, 행정문서 내용 규칙, 템플릿 | 해당 형식 작업 시 |

## 준비물

1. 볼트로 쓸 폴더 하나 (옵시디언 볼트 권장)
2. 그 안에 `0_원본/` 폴더
3. LLM 대화 내보내기(md), 이력서, 기존 산출물 등을 `0_원본/`에 투입 — 파일명 자유, 분류 불필요

> 특히 좋은 재료: 결과물이 마음에 안 들어 여러 번 고친 대화, 선택지 중 하나를 고른 대화.
> 학생 이름·학번·성적·상담 내용은 익명화해서 넣으세요.

## 시작하기

```
# 1. 스킬 설치 (컴퓨터당 1회)
git clone https://github.com/dohyun851208/second-brain "%USERPROFILE%\.claude\skills\second-brain"
#    (macOS/Linux: ~/.claude/skills/second-brain)

# 2. 볼트 폴더에서 Claude Code 실행
cd 내볼트폴더
claude
```

3. **"세컨드브레인 시작"** → 볼트에 구조 자동 생성 (기존 파일은 절대 건드리지 않음)
4. **"컴파일해줘"** → 대화 분석 → 확인 질문 몇 개 → 나만의 두뇌 v1.0
5. 끝. 이후 이 폴더에서 여는 모든 세션은 자동으로 나의 두뇌를 사용합니다.
   스킬은 더 필요 없고, Codex도 `AGENTS.md`를 읽어 동일하게 작동합니다.

## 일상 사용

- **검수·선택**: "이 수업안 검수해줘" → ①선택 ②왜 나다운가 ③수정 예상 지점 ④수정안 ⑤확인 필요
- **한글·엑셀**: 볼트에서 실행하면 다른 폴더의 hwp/hwpx/xlsx도 처리합니다. 완성본은 원본 옆에 `_완성본`으로 저장되고 원본은 덮어쓰지 않습니다.
- **두뇌 성장**: 새 대화를 `0_원본/`에 넣어두면 다음 세션 시작 때 자동 감지 → 승인하면 두뇌가 갱신됩니다.
- **교정**: 결과가 "나답지 않다"고 말하면 해당 규칙이 수정되고 이력이 남습니다.

## 개인정보

볼트는 내 컴퓨터에만 있습니다. 이 저장소에는 빈 템플릿(구조)만 있으며 누구의 개인 데이터도 포함하지 않습니다.

## 업데이트

스킬 폴더에서 `git pull` 후, 볼트에서 **"세컨드브레인 업그레이드"** — 시스템 파일만 갱신되고 내 원본·두뇌·이력은 보존됩니다.
