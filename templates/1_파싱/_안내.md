# 1_파싱 사용법

**여기는 자동 생성 폴더다 — 직접 파일을 넣거나 고치지 말 것.**
"파싱해줘"(또는 컴파일의 1단계)가 실행되면 `0_원본/`의 모든 파일이 md로 변환되어 여기에 쌓인다.
원본과 같은 상대 경로, 파일명은 `원본이름.원본확장자.md` (md 원본은 같은 이름 그대로).

- 각 파일 맨 위 frontmatter가 어느 원본에서 언제 무슨 도구로 변환됐는지 기록한다
- 재파싱하면 덮어써진다 — 내용을 고치고 싶으면 `0_원본/`의 원본을 고치고 재파싱을 요청할 것
- 증류(컴파일)는 이 폴더만 입력으로 삼는다 — 증류 전에 표·서식 많은 문서의 변환 품질을 한번 훑어보면 좋다
- 규칙의 출처 링크도 이 폴더를 가리킨다 (드릴다운이 원본 대신 여기를 읽는다)
- 절차 정본: `8_시스템/파서-프롬프트.md`
