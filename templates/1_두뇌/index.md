# 두뇌 색인

지휘자는 작업 시작 시 이 파일을 먼저 읽고, 담당 영역이 맞는 모듈만 연다.

**두뇌 버전: v0.0 (미컴파일)** | 최종 갱신: -

| 모듈 | 담당 영역 | 규칙 수 | 최종 갱신 |
|---|---|---|---|
| 판단기준-공통.md | 모든 작업 공통 판단 (고정 앵커) | 0 | - |
| 수업설계.md | 수업·활동지·평가·루브릭 | 0 | - |
| 웹앱-코딩.md | 수업용 웹앱·코드·디지털 도구 | 0 | - |
| 글쓰기.md | 이력서·지원서·문서·안내문 | 0 | - |
| 팩트카드.md | 개인 사실 정보 (고정 앵커) | - | - |

**모듈 구성은 컴파일러의 자유다.** 데이터가 요구하면 새 모듈·폴더를 만들고, 나누고, 합쳐도 된다
(위 도메인 모듈들은 초기 제안 틀일 뿐). 단 모든 모듈은 이 색인에 담당 영역과 함께 등록해야
지휘자가 찾을 수 있고, 고정 앵커 2개(판단기준-공통, 팩트카드)는 유지한다.

세션 시작 점검의 기준. `0_원본/`의 실제 목록·수정시각이 이 표와 다르면 두뇌가 낡은 상태 → 증분 컴파일 필요.
