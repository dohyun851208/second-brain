# 0_원본 사용법

**뭐든 그냥 여기에 넣으면 된다.** LLM 대화, 이력서, 기존 수업안, 웹앱 코드, 완성 문서 — 종류 구분 없이.
컴파일러가 내용을 읽고 유형(대화 → 규칙 추출 / 사실 자료 → 팩트카드 / 완성 산출물 → 판례 후보)을 알아서 판별한다.

- 파일명 자유. 하위 폴더를 만들어 정리해도 되고 안 해도 된다 (시스템은 신경 안 씀)
- 시스템은 원본을 절대 수정·이동·개명하지 않는다
- 컴파일 후 파일명을 바꾸면 규칙의 출처 링크가 끊긴다 (lint가 감지하지만 가급적 유지)
- 학생 이름·학번·성적·상담 내용은 익명화해서 넣을 것 (본인 정보는 자유 — 개인용 시스템)

## 특히 좋은 원료가 되는 대화

- 결과물이 마음에 안 들어 여러 번 고친 대화
- 선택지 중 하나를 고른 대화, "이건 우리 반에서 안 된다"고 판단한 대화
- 대화 파일 맨 위에 작업 맥락 한 줄(예: "5학년 사회 수업용 웹앱 만들던 대화")을 붙이면 컴파일 정확도가 올라간다
- 가능하면 끝에 4줄: 마음에 든 부분 / 안 든 부분 / 최종 선택 / 그 이유
