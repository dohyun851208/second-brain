# 7_개인정보이미지 사용법

문서에 **이미지 형태 그대로** 삽입·첨부할 개인 자산을 보관한다.

- 여기에 둘 것: 서명, 도장, 신분증, 통장사본, 증명사진, 반복 사용할 기타 개인정보 사진처럼 픽셀 원형이 필요한 이미지 (`기타이미지/` 포함)
- `0_원본/`에 둘 것: 내용을 OCR해 텍스트·지식으로 사용할 스캔, 캡처, 사진
- 분류 기준은 확장자가 아니라 용도다: **읽을 이미지 → `0_원본/`, 쓸 이미지 → `7_개인정보이미지/`**

## 절대 규칙

1. 이 폴더는 컴파일·파싱·증류 대상이 아니다. `1_파싱/`이나 `2_두뇌/`에 내용·OCR 결과를 저장하지 않는다.
2. 원본 파일의 이름·내용·위치를 바꾸거나 덮어쓰지 않는다. 크기 조절·자르기·배경 제거가 필요하면 출력 문서나 임시 작업 사본에서만 한다.
3. 먼저 `자산목록.md`만 읽고 필요한 후보를 고른다. 요청과 무관한 이미지 파일을 열거나 일괄 OCR하지 않는다.
4. 일반적인 "양식 작성" 요청은 양식 분석과 자산 후보 제안까지 허용한다. 쓰기 전에 필수·선택 항목과 이미지 칸·별도 첨부·서명·날인란을 전체 점검한다. 작업 중 새로 발견했더라도 같은 규칙을 적용한다.
5. 필수 신분증·통장사본·증명사진·서명·날인 등 민감 이미지 사용이 필요하지만 아직 승인이 없으면, 사용 예정 자산과 용도를 한 번에 제시해 확인한다. 승인되면 같은 작업을 이어서 완료한다. 선택·모호한 이미지란은 자동 삽입하지 않는다.
6. 사용자가 특정 문서와 자산을 명시해 "서명까지 넣어줘", "통장사본을 첨부해줘"처럼 요청한 경우에는 그 문서·자산 범위의 승인으로 본다. 다른 문서나 다른 자산으로 확대하지 않는다.
7. 필수란을 미승인 상태로 말없이 비우고 완성본이라고 보고하지 않는다. 사용자가 사용을 거부하면 해당 칸을 비운 미완성본으로 받을지 작업을 중단할지 확인한다.
8. 사용이 끝나면 `사용기록.md`에 날짜·자산 ID·산출물·용도를 기록한다. 주민번호·계좌번호 등 실제 민감 값은 기록하지 않는다.

## 문서 작성 흐름

1. 대상 양식에 쓰기 전에 필수·선택 항목과 이미지 칸·별도 첨부·서명·날인란을 모두 찾는다.
2. 일반 내용은 `2_두뇌/`의 팩트카드·관련 모듈에서 가져온다.
3. `자산목록.md`에서 필요한 이미지 후보만 고른다.
4. 필수 자산의 사용 승인을 확인하고 필요한 파일만 연다. 미승인이라면 이 지점에서 한 번 확인한다.
5. 새 HWPX를 생성하면서 개인정보 이미지를 넣는다면 `9_형식/라우팅.md`에 따라 Kordoc `generate --image-dir`를 사용한다. 기존 `.hwp`/`.hwpx`의 지정 위치에 넣어야 할 때만 `place_image.py` 실측 배치를 실행하며, `.hwp`는 이 예외 안에서만 임시 HWPX로 한 번 변환한다. 양식이 별도 파일 첨부를 요구하면 문서 안 삽입으로 대체하지 않는다.
6. 원본 양식과 원본 이미지를 보존한 별도 산출물을 만든다.
7. 주요 값·첨부·서명 위치를 검증하고 사용 기록을 남긴다.
