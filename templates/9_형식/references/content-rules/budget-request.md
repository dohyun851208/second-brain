# 성립전 예산 요구서 내용 규칙

성립전 예산 요구서, 부서예산요구서, 예산표는 `references/workflows/xlsx-forms.md`를 먼저 따른 뒤, 이 문서의 내용 규칙을 적용한다.

## 기본 구조

- 제목은 `학년도 + 학교회계 부서예산요구서 + (성립전예산)` 형식을 우선한다.
- 상단에는 `부서명`과 금액 단위를 표시한다. 학교 예산 요구서에서는 보통 `단위: 천원`을 사용한다.
- 표 헤더는 다음 순서를 기본으로 한다.
  - 세부사업
  - 세부항목
  - 원가통계비목
  - 산출내역
  - 산출기초
  - 기정예산액 또는 기존예산액 `(A)`
  - 경정예산요구액 또는 증감 요구액 `(B)`
  - 최종예산액 `(C=A+B)`
  - 비고

## 작성 방식

- 같은 세부사업이나 세부항목이 여러 행에 걸치면 해당 열을 세로 병합한다.
- 한 행에는 하나의 예산 비목 또는 산출 항목만 넣는다.
- `산출내역`은 무엇을 사거나 운영하는지 짧게 쓴다.
- `산출기초`는 `단가*수량`, `단가*횟수`, `단가*명*회`처럼 계산 근거가 보이게 쓴다.
- 금액 열은 양식 단위를 따른다. `단위: 천원`이면 원 단위 총액을 1,000으로 나누어 입력한다.
- 증액 요구는 양수, 감액 요구는 `경정예산요구액(B)`에 음수로 입력한다.

## 수식과 검산

- 행별 `최종예산액`은 `기정예산액 + 경정예산요구액` 수식을 유지한다.
- 합계 행은 각 금액 열의 `SUM` 수식을 유지한다.
- 행을 추가하거나 삭제하면 합계 범위와 행별 수식이 새 데이터 영역을 포함하는지 확인한다.
- 수식 셀은 값으로 덮어쓰지 않는다.

## 서식 보존

- 제목 행, 부서명 행, 단위 표시, 헤더 병합셀은 유지한다.
- 헤더는 굵게, 가운데 정렬, 배경색, 테두리를 보존한다.
- 데이터 행은 기존 글꼴, 테두리, 세로 가운데 정렬, 숫자 서식을 복사한다.
- 금액 열은 천 단위 구분과 음수 빨간색 표시 같은 기존 숫자 서식을 유지한다.
- 안내 문구가 있으면 삭제하지 않는다. 예: 감액 요구 시 음수 표시 안내.

## 검토

- 부서명, 학년도, 사업명, 세부항목이 제출 목적과 맞는지 확인한다.
- 원가통계비목이 산출내역과 어긋나지 않는지 확인한다.
- 산출기초의 원 단위 계산과 금액 열의 천원 단위 입력이 일치하는지 확인한다.
- 최종예산액과 합계가 수식으로 계산되는지 다시 열어 검증한다.
