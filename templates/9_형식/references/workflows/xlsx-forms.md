# XLS/XLSX 양식 작성

Excel 양식은 `openpyxl`을 기본으로 사용한다. 기존 서식과 병합 구조를 먼저 확인하고, 작성 후 저장 파일을 다시 열어 검증한다.

## 기본 흐름

1. workbook, sheet 목록 확인
2. 병합셀 범위 확인
3. 헤더/데이터 영역 파악
4. 필요한 경우 데이터 영역의 병합셀을 안전하게 unmerge 후 작성
5. 기존 스타일을 복사해 데이터 행에 적용
6. 저장 후 재열기 검증

## 서식 원칙

- 기존 서식은 최대한 보존한다.
- 기울임체 사용 금지: `italic=False`
- 글꼴 색상은 검정: `FF000000`
- 정렬은 가운데: `horizontal='center'`, `vertical='center'`
- 데이터 영역에는 thin border 적용
- 긴 텍스트는 `wrap_text=True`, 열 너비와 행 높이를 조정한다.
- 1인 데이터가 여러 행에 걸치면 연번, 학교급, 소속, 성명 같은 반복 열은 병합한다.

## 병합셀 처리

- 작성 대상 셀이 `MergedCell`인지 확인한다.
- 병합 범위의 좌상단 셀에만 값을 쓸 수 있다.
- 데이터 영역에서 값 입력이 막히면 해당 범위를 unmerge하고, 필요한 값을 입력한 뒤 같은 사람 단위로 다시 merge한다.

## 검증

- 저장한 파일을 `openpyxl.load_workbook()`으로 다시 연다.
- 주요 셀 값, 병합 범위, 스타일 일부를 확인한다.
- 사용자가 제출용 파일을 요구하면 불필요한 임시 시트나 계산 보조값을 남기지 않는다.
